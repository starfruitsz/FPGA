# VGA 示波器（分层 + 特性开关）

给 `project_2025_11_07`（高云 GW5A-25A）加 640×480 VGA 波形显示。
**HAL / 抽象 / 应用** 分层，**引脚表与视频参数外置**，**时基运行时可调**，
**4 个特性各有开关**。

---

## 0. 特性开关（一处配置）

在 `adda_scope_top.v` 顶部：

| 开关 | 默认 | 对应特性 | 关掉后的效果 |
|---|---|---|---|
| `FEAT_TRIG` | 1 | 触发对齐：检测电平穿越并把写指针归零 | 自由采集，波形会左右轻微漂移 |
| `FEAT_MEAS` | 1 | 自动测量：帧内峰峰值 / 过零次数 | 第二行显示 `VP=0000 FR=0000`，测量逻辑不综合 |
| `FEAT_SCROLL` | 1 | 滚动显示：以帧起始写指针为基准 | 只显示缓冲区前 640 点（静态窗） |
| `FEAT_UART` | 1 | 串口在线配置（T/R/A/L/E/S 命令） | `cfg_*` 输入被忽略，只保留按键 |

开关最终传给 `vga_scope_top` 的 `FEAT_*` 参数，用 `generate` /
参数选择实现"关闭 = 逻辑不进入网表"（测量模块整块不例化，滚动读地址退化为 `px`）。

## 3. 配置

### 3.1 引脚（综合前）

改 `pins/scope_pins.csv` → `python pins/gen_cst.py` → 生成
`project_2025_11_07_scope.cst`。RTL 不含任何引脚信息。

VGA 的 8 个引脚已按 **PnR 报告的 All Package Pins** 选出 bank 4 的空闲 IO（全部 3.3V、
未与现有 30 个端口及自动布局的数码管引脚冲突），并已写入工程约束
`FPGA/src/project_2025_11_07.cst`：

| 端口 | 引脚 | Site | 接法 |
|---|---|---|---|
| `vga_hs` | T11 | IOB45[B] | DE-15 脚 13 |
| `vga_vs` | T12 | IOB43[A] | DE-15 脚 14 |
| `vga_rgb[11]` | U13 | IOB50[A] | R1 → 270Ω |
| `vga_rgb[10]` | R10 | IOB35[A] | R0 → 560Ω |
| `vga_rgb[7]` | U11 | IOB39[A] | G1 → 270Ω |
| `vga_rgb[6]` | N12 | IOB52[A] | G0 → 560Ω |
| `vga_rgb[3]` | V14 | IOB54[B] | B1 → 270Ω |
| `vga_rgb[2]` | M11 | IOB48[A] | B0 → 560Ω |

> 这 8 个脚来自报告里 `Signal="-"` 的空闲 IO；如果板卡上这些脚已被其它器件占用，
> 改 CSV 后重新生成即可。换到别的 bank 时注意 BankVccio 要与电阻网络一致（3.3V）。

### 3.3 运行时

**按键**

| 操作 | 效果 |
|---|---|
| 短按 `key_in` | 时基 8 档循环：1k/5k/25k/100k/500k/5M/50M S/s |
| 长按 >800ms | 运行 / 冻结 |

**串口（特性4）**：与原有 A/B 二进制帧共用同一个 `rx` 引脚（独立第二路 uart_rx），
ASCII 命令以 CR/LF 结尾：

| 命令 | 例子 | 含义 |
|---|---|---|
| `T<hex4>` | `T0063` | 采样分频 = 0x0063（约 500 kS/s） |
| `R<0/1>` | `R0` | 0=冻结 1=运行 |
| `A<0/1>` | `A1` | 触发使能 |
| `L<hex3>` | `L200` | 触发电平 = 0x200（512） |
| `E<0/1>` | `E0` | 触发边沿：0=上升 1=下降 |
| `S<0/1>` | `S1` | 滚动显示使能 |

> 非十六进制字节被当作命令字母；二进制 A/B 帧不含 CR，不会误提交。

**显示布局**

~~~
行0: AD=####  U=####  TB=####      (AD 输入 / DAC 输出 / 时基分频)
行1: VP=####  FR=####              (峰峰值 / 过零×60Hz 约等于频率)
~~~

## 4. 四个特性的实现

1. **触发（scope_capture）**：按采样节拍比较上一拍与当前采样，
   上升沿为 `(din_d<level)&&(din>=level)`，下降沿反之；命中时把写指针清零，
   显示从触发点开始（±1 采样）。
2. **测量（scope_meas）**：帧起始清零，帧内跟踪 min/max 与过零上升次数；
   帧起始时输出 `vpp=vmax-vmin` 与 `freq=cnt*60`（帧频约 60Hz）。
3. **滚动（vga_scope_top）**：帧起始锁存写指针 `rd_base`，读地址 =
   `rd_base-640+px`，最右列永远是最新采样。
4. **串口（scope_cmd）**：逐字节解析，命令字母 + 十六进制累加，CR/LF 提交为单周期写使能；
   `scope_app` 中串口写优先于按键。

---

## 5. 显示原理（无帧缓存）

每个像素列：读采样 RAM（1 拍延迟）→ 相邻两点各自映射 y → 用竖线填满两点之间 →
在像素周期后半拍求值、`pix_ce` 打入输出寄存器，`hs/vs/de` 延迟 2 拍对齐。
坐标映射 `y = 447 - (s×7>>4)`，网格 64×64，零轴 y=224。

## 9. 已知限制

1. 触发为"指针归零"式对齐，无预触发深度/无单次捕获模式；
2. 频率是"帧内过零数 × 60"，分辨率 60Hz，且以固定阈值 512 判定；
3. 滚动模式每帧更新一次基准，极高采样率下会出现帧间跳变；
4. 串口命令为 ASCII 文本，与二进制 A/B 帧共享线路，极端情况下可能被误解析；
5. 文本为 2 行固定模板，暂不支持任意字符串。
